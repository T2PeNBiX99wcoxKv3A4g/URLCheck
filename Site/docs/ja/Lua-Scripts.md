# Lua スクリプト

URLCheck は、入ってくるすべての URL に対して小さな Lua スクリプトを実行できます。スクリプトは
URL を調べ、変更し、返すことができます。これは確認用ポップアップが開く前、そして何かがブラウザに
届く前に行われます。

このページではスクリプトの仕組みを説明します。サンドボックスが提供するすべての関数については
[API リファレンス](API) を参照してください。すぐに使えるスクリプトについては
[Lua スクリプトの例](Lua-Script-Examples) を参照してください。

## スクリプトの場所

スクリプトは、URLCheck の設定やログと同じ場所にある `scripts` フォルダー内の単なる `.lua`
ファイルです。Windows では次の場所です。

```
%APPDATA%\URLCheck\scripts
```

Scripts ページには、お使いのシステムでの正確なフォルダーが表示されます。リスト右上のフォルダー名に
マウスを重ねてください。

そのフォルダー内のすべての `.lua` ファイルが読み込まれます。任意のエディターでファイルを追加、
編集、名前変更、削除できます。フォルダーが変更されると Scripts ページは自動的に更新されます。
このページには、スクリプトを作成、インポート、ダウンロードするためのボタンもあります。

### スクリプトの共有

VPM リンクがパッケージを追加するのと同じ方法で、リンクからスクリプトをインストールできます。

```
checkurl://script?url=<the script's URL, percent-encoded>
```

例:

```
checkurl://script?url=https%3A%2F%2Fraw.githubusercontent.com%2FT2PeNBiX99wcoxKv3A4g%2FURLCheck%2Fmaster%2FLua%2Fx-twitter-remove-params.lua
```

クリックするとスクリプトがフォルダーにダウンロードされ、Scripts ページが開きます。URLCheck は
**設定 → システム統合** で **Register http/https** を押したときに、`http`/`https` と一緒に
`checkurl://` スキームを登録します。リンクを押しても何も起こらない場合は、一度押してください。

## スクリプトの構成

スクリプト ファイルは読み込まれたときに一度だけ実行され、**関数を返す必要があります**。その関数は
URL ごとに一度呼び出されます。

```lua
-- This part runs once, when the script is loaded.
local tracking = { "utm_source", "utm_medium", "utm_campaign", "fbclid", "gclid" }

-- This is the part that runs for every URL.
return function(u)
    for _, name in ipairs(tracking) do
        u.query[name] = nil
    end

    return u
end
```

関数を返さないファイルは、Scripts ページに警告付きで一覧表示され、実行されません。

スクリプトは **ファイル名順** に実行されます。各スクリプトは前のスクリプトが生成した URL を
受け取るため、`01-strip-tracking.lua` は `02-force-https.lua` より先に実行されます。各スクリプトは
独自の Lua ステートを持ち、関数の外で設定したローカル変数やグローバルは URL 間で保持されます。

## `u` テーブル

関数は 1 つのテーブルを受け取り、通常は `u` と呼ばれます。その URL フィールドは
**URL デコード済み** であるため、スクリプトはプレーン テキストを扱うだけでよく、自分で
アンエスケープする必要はありません。

| フィールド      | 型              | 説明                                                                                                                           |
|-----------------|-----------------|--------------------------------------------------------------------------------------------------------------------------------|
| `u.url`         | string          | URL 全体（パーセント デコード済み）。情報用です。後述を参照。                                                                   |
| `u.scheme`      | string          | `http` または `https`。                                                                                                        |
| `u.host`        | string          | ホスト名。たとえば `example.com`。                                                                                              |
| `u.port`        | number または `nil` | 明示的なポート。URL が既定のポートを使っている場合は `nil`。                                                                |
| `u.path`        | string          | パス（デコード済み）。常に `/` で始まります。                                                                                   |
| `u.fragment`    | string または `nil` | `#` より後の部分（デコード済み）。URL にない場合は `nil`。                                                                  |
| `u.query`       | table           | デコードされたクエリ パラメーター。たとえば `{ q = "hello world", page = "2" }`。URL にクエリがなくても常にテーブルです。        |
| `u.app_version` | string          | 実行中の URLCheck のバージョン。                                                                                                |

次のような URL の場合、

```
https://example.com/a%20b?q=hello%20world&plus=a+b&x=%2B#frag%20ment
```

スクリプトからはこのように見えます。

```lua
u.url       -- "https://example.com/a b?q=hello world&plus=a+b&x=+#frag ment"
u.scheme    -- "https"
u.host      -- "example.com"
u.port      -- nil
u.path      -- "/a b"
u.fragment  -- "frag ment"
u.query     -- { q = "hello world", plus = "a b", x = "+" }
```

### `u.query`

`u.query` はスクリプトが最もよく触る部分です。

```lua
u.query["utm_source"] = nil      -- remove one parameter
u.query["ref"] = "urlcheck"      -- add one (or replace its value)
u.query = nil                    -- drop the whole query
u.query = {}                     -- same thing, with an empty table
```

- キーと値は常に文字列です。`a=1` は `u.query["a"] == "1"` になります。数値が必要な場合は
  `tonumber()` を使ってください。
- `%XX` エスケープと `+` はデコードされます（`+` はスペースに、`%2B` は `+` になります）。
- URL 内に 2 回現れるパラメーターは **最後** の値を保持します。
- 文字列でない値（数値、真偽値）は、URL の再構築時にテキストへ変換されます。
- 元のパラメーターは順序を保持し、スクリプトが追加したパラメーターはその後に名前順で並びます。
  同じ入力からは常に同じ URL が生成されます。
- `pairs` で反復しながらキーを削除するのは、現在のキーに対してのみ安全です。複数削除する場合は、
  先に名前を集めてください。

## 結果を返す

戻り値によって、URL がどうなるかが決まります。

| 戻り値                                             | 効果                                                                                          |
|----------------------------------------------------|-----------------------------------------------------------------------------------------------|
| `u`                                                | `u.scheme`、`u.host`、`u.port`、`u.path`、`u.query`、`u.fragment` から URL が再構築されます。 |
| URL 文字列。たとえば `"https://example.com/"`      | URL がその文字列に置き換えられます。                                                          |
| `nil`（または何も返さない）                        | URL はまったくそのまま残ります。                                                              |

```lua
return function(u)
    if u.host == "old.example" then
        return "https://new.example" .. u.path
    end

    return u
end
```

知っておく価値のあることが 2 つあります。

- **`u` を返す場合、`u.url` を編集しても何も起こりません。** URL は上記のフィールドから再構築され、
  `u.url` は読み取り用です。URL 全体を置き換えたい場合は文字列を返してください。
- `u.scheme` または `u.host` が空になった場合、元の URL が変更されずに保持されます。

## エンコーディング

取り決めは単純です。**入力時はデコード済み、出力時はエンコード済み。**

- `u.url`、`u.path`、`u.fragment`、および `u.query` のすべてのキーと値はデコードされた状態で
  渡されます。
- URL が再構築されるとき、スペースと非 ASCII テキストは再びエンコードされ（`%20`、`%E4%B8%AD` など）、
  パス セグメントは 1 つずつエスケープされるため `/` は区切りのまま残り、クエリのキーと値は個別に
  エスケープされます。そのため `&` や `=` を含む値は 1 つの値のままです。
- 文字列として返される URL では、URL が運べない文字（スペース、制御文字、非 ASCII、および
  `` " < > \ ^ ` { | } ``）だけがエスケープされます。構造 — `: / ? # & = %` — はそのまま残るため、
  デコード済みの部品から URL を組み立てて返すことができます。

そのため、クエリ文字列を手で組み立てるよりも `u.query` を変更する方が好ましいです。

```lua
-- good: the value is escaped for you
u.query["q"] = "a b&c"           -- -> q=a%20b%26c

-- avoid: the & and the spaces are ambiguous
return "https://example.com/?q=" .. u.query["q"]
```

## `print`

`print` は Scripts ページ下部の **Lua ログ** に 1 行書き込みます。ポップアップには表示されず、
何も開きません。

```lua
return function(u)
    print("host:", u.host)
    print("query:", u.query)

    return u
end
```

- 値は Lua 標準の `print` と同様にタブで区切られます。
- Lua と異なり、テーブルはアドレスではなく **展開** されます:
  `{ a = 1, b = "two", c = { [2] = 3, d = true } }`。テーブル内の文字列は引用符で囲まれ、
  エスケープされます。自身を含むテーブルは `{...}` として表示され、ネストは 6 階層で停止します。
- 各行にはスクリプトのファイル名が付くため、複数のスクリプトがログを共有できます。

ログは最新 200 行を保持します。**Clear** ボタンで消去できます。

## サンドボックスと制限

スクリプトは、テキストと数値だけを扱えるサンドボックス内で実行されます。

- **利用可能:** 基本ライブラリ（[_G](_G)）、[string](string)、[table](table)、[math](math)、
  [bit32](bit32)、[coroutine](coroutine)。
- **利用不可:** `io`、`os`、`debug`、`package`、`require`、`dofile`、`loadfile`。スクリプトは
  ファイルを読んだり、ネットワークにアクセスしたり、プログラムを起動したりできません。
- 各スクリプトには URL ごとに **2 秒** が与えられます。それより長く実行されるスクリプトは停止され、
  エラーとして扱われます。

## エラー

- **ファイルがコンパイルできない:** 警告アイコン付きで一覧表示され、マウスを重ねるとメッセージが
  表示されます。エディターは解析できないスクリプトの保存を拒否します。
- **ファイルが関数を返さない:** リストに「The script must return a function.」と表示されます。
- **関数が例外を投げる、またはタイムアウトする:** URL はそのまま残り、残りのスクリプトは引き続き
  実行され、ポップアップにエラーが表示され、完全なメッセージが Lua ログに書き込まれます。

## Scripts ページ

Scripts ページはこのフォルダーのエディターです。

- **左側:** ディスク上のスクリプト。読み込まれないスクリプトの横には警告アイコンが付きます。下部の
  フローティング カードで、新しいスクリプトの作成、ファイルのインポート、URL からのスクリプトの
  ダウンロードができます。
- **右側:** 選択したスクリプトのエディター。
  - **鉛筆** はファイル名を変更します（Enter で確定、Escape でキャンセル）。
  - **Open** はそのファイルを `.lua` ファイル用のシステム既定のプログラムで開きます。
  - **Save**（または `Ctrl`/`Cmd` + `S`）はファイルを書き込みます。
  - **ゴミ箱** は削除します。確定するには 2 回クリックします。
- **テスト ボックス:** URL を入力して **Test**（または Enter）を押します。スクリプトはエディター内の
  状態のまま（未保存の変更も含めて）実行され、結果として最終的な URL またはエラーが表示されます。
  何も開かれず、履歴にも何も追加されません。スクリプトが `print` したものはすべて Lua ログに
  入ります。
- **Lua ログ:** スクリプトが出力したもの、または失敗した内容。新しいものが最後です。

リストはフォルダーに追従します。別のプログラムで追加、名前変更、削除されたファイルは自動的に
反映されます。編集中のファイルが未保存の変更を抱えたまま削除された場合、エディターはそれを保持し、
警告を付けます。保存するとファイルが再び書き込まれます。
