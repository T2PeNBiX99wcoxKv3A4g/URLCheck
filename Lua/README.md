# Scripts

Install any of these from the scripts page with one click:

**[Open the scripts page](https://t2penbix99wcoxkv3a4g.github.io/URLCheck/#/scripts)**

| Script                         | What it does                                                                                          |
|--------------------------------|-------------------------------------------------------------------------------------------------------|
| `x-twitter-remove-params.lua`  | Drops every query parameter on x.com and twitter.com, subdomains included.                            |
| `strip-tracking-params.lua`    | Removes common tracking parameters (`utm_*`, `fbclid`, `gclid`, …) from every URL, whatever the host. |
| `force-https.lua`              | Upgrades `http://` links to `https://`.                                                               |
| `youtube-remove-si.lua`        | Removes YouTube's `si` share token and the `feature`/`pp` flags.                                      |
| `bilibili-remove-tracking.lua` | Removes Bilibili's share and tracking parameters (`spm_id_from`, `vd_source`, …).                     |
| `amazon-remove-tracking.lua`   | Removes Amazon's `pf_rd_*`, `ref` and `ref_` parameters.                                              |
| `old-reddit.lua`               | Opens Reddit on the old interface (`old.reddit.com`).                                                 |
| `remove-empty-params.lua`      | Drops query parameters that have an empty value.                                                      |

The page is generated from this folder, so it always lists the current files.
