# スクリプト

スクリプト ページから、どれでもワンクリックでインストールできます。

**[スクリプト ページを開く](https://t2penbix99wcoxkv3a4g.github.io/URLCheck/#/scripts)**

| スクリプト                     | 内容                                                                                                  |
|--------------------------------|-------------------------------------------------------------------------------------------------------|
| `x-twitter-remove-params.lua`  | x.com と twitter.com（サブドメインを含む）のクエリ パラメーターをすべて削除します。                    |
| `strip-tracking-params.lua`    | ホストに関係なく、すべての URL から一般的なトラッキング パラメーター（`utm_*`、`fbclid`、`gclid` など）を削除します。 |
| `force-https.lua`              | `http://` のリンクを `https://` にアップグレードします。                                              |
| `youtube-remove-si.lua`        | YouTube の `si` 共有トークンと `feature`/`pp` フラグを削除します。                                     |
| `bilibili-remove-tracking.lua` | Bilibili の共有・トラッキング パラメーター（`spm_id_from`、`vd_source` など）を削除します。            |
| `amazon-remove-tracking.lua`   | Amazon の `pf_rd_*`、`ref`、`ref_` パラメーターを削除します。                                          |
| `old-reddit.lua`               | Reddit を旧インターフェース（`old.reddit.com`）で開きます。                                           |
| `remove-empty-params.lua`      | 値が空のクエリ パラメーターを削除します。                                                              |
| `skip-redirects.lua`           | リダイレクト リンク（`?q=`、`?url=`、`?u=`、`?uddg=` など）に隠された宛先へ直接ジャンプします。        |

このページはこのフォルダーから生成されるため、常に現在のファイルが一覧表示されます。
