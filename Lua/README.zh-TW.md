# 腳本

[English](README.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md)

在腳本頁面一鍵安裝下列任何一個腳本：

**[開啟腳本頁面](https://t2penbix99wcoxkv3a4g.github.io/URLCheck/#/scripts)**

| 腳本                           | 功能                                                                                                  |
|--------------------------------|-------------------------------------------------------------------------------------------------------|
| `x-twitter-remove-params.lua`  | 移除 x.com 與 twitter.com（含子網域）上的所有查詢參數。                                               |
| `strip-tracking-params.lua`    | 從每個 URL 移除常見的追蹤參數（`utm_*`、`fbclid`、`gclid`、…），不論主機為何。                        |
| `force-https.lua`              | 將 `http://` 連結升級為 `https://`。                                                                  |
| `youtube-remove-si.lua`        | 移除 YouTube 的 `si` 分享權杖以及 `feature`/`pp` 旗標。                                                |
| `bilibili-remove-tracking.lua` | 移除 Bilibili 的分享與追蹤參數（`spm_id_from`、`vd_source`、…）。                                     |
| `amazon-remove-tracking.lua`   | 移除 Amazon 的 `pf_rd_*`、`ref` 與 `ref_` 參數。                                                      |
| `old-reddit.lua`               | 以舊版介面（`old.reddit.com`）開啟 Reddit。                                                           |
| `remove-empty-params.lua`      | 移除值為空的查詢參數。                                                                                |
| `skip-redirects.lua`           | 直接跳到重新導向連結中隱藏的目標（`?q=`、`?url=`、`?u=`、`?uddg=` …）。                              |

此頁面是由這個資料夾產生，因此永遠會列出目前的檔案。
