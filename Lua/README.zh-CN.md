# 脚本

[English](README.md) · [日本語](README.ja.md) · [繁體中文](README.zh-TW.md)

在脚本页面一键安装其中任意一个：

**[打开脚本页面](https://t2penbix99wcoxkv3a4g.github.io/URLCheck/#/scripts)**

| 脚本                           | 作用                                                                                                  |
|--------------------------------|-------------------------------------------------------------------------------------------------------|
| `x-twitter-remove-params.lua`  | 丢弃 x.com 和 twitter.com（含子域名）上的所有查询参数。                                                |
| `strip-tracking-params.lua`    | 从所有 URL 中移除常见跟踪参数（`utm_*`、`fbclid`、`gclid` 等），无论主机是什么。                      |
| `force-https.lua`              | 把 `http://` 链接升级为 `https://`。                                                                   |
| `youtube-remove-si.lua`        | 移除 YouTube 的 `si` 分享令牌以及 `feature`/`pp` 标志。                                                |
| `bilibili-remove-tracking.lua` | 移除 Bilibili 的分享和跟踪参数（`spm_id_from`、`vd_source` 等）。                                      |
| `amazon-remove-tracking.lua`   | 移除 Amazon 的 `pf_rd_*`、`ref` 和 `ref_` 参数。                                                       |
| `old-reddit.lua`               | 用旧版界面打开 Reddit（`old.reddit.com`）。                                                            |
| `remove-empty-params.lua`      | 丢弃值为空的查询参数。                                                                                 |
| `skip-redirects.lua`           | 直接跳到重定向链接中隐藏的目标地址（`?q=`、`?url=`、`?u=`、`?uddg=` 等）。                             |

该页面由这个文件夹生成，因此始终列出当前的文件。
